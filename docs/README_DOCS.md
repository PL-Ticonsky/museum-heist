# Museum Heist Documentation Index

This folder contains the technical, testing, and exposition documentation for the Museum Heist Computer Science I project. The documents are based on the current repository code and data files.

## Technical Documentation

- [01_project_overview.md](technical/01_project_overview.md): project purpose, objective, mechanics, technologies, and course requirement coverage.
- [02_architecture.md](technical/02_architecture.md): system architecture, C++ engine, Python algorithms, Pygame UI, JSON bridge, and execution flow.
- [03_json_bridge.md](technical/03_json_bridge.md): `input.json`, `state.json`, field descriptions, communication flow, and JSON examples.
- [04_cpp_engine.md](technical/04_cpp_engine.md): C++ engine behavior, difficulty maps, movement validation, game rules, output generation, and compile command.
- [05_data_structures.md](technical/05_data_structures.md): custom linked list and binary search tree implementations, diagrams, and complexity.
- [06_greedy_algorithm.md](technical/06_greedy_algorithm.md): greedy item selection, pseudocode, complexity, and UI visualization.
- [07_backtracking_algorithm.md](technical/07_backtracking_algorithm.md): recursive route search, state representation, invalid cells, pseudocode, complexity, and UI visualization.
- [08_pygame_ui.md](technical/08_pygame_ui.md): Pygame screens, rendering order, controls, timer, and final metrics.
- [09_game_rules.md](technical/09_game_rules.md): movement, item collection, danger zones, alarm, limits, win and lose conditions, restart, and main menu behavior.

## Testing Documentation
